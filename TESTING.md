# Проверки версии 0.3.0

В этой сессии доступен репозиторий плагина, без установленного Moodle и его БД.
Для локальной проверки в игнорируемую папку `work/php-runtime` распакован PHP 8.4.24.

Выполнено:

- Проверка PHP-синтаксиса всех 25 PHP-файлов плагина и тестов.
- Изолированный запуск 9 методов из `network_test` и `exercise_test`:
  **63 949 утверждений**, все прошли. Локальный запуск использует небольшой
  assertion harness; это не запуск PHPUnit и не интеграционная проверка Moodle.
- Проверены все примеры из таблицы требований, перенос через границы октетов,
  неоктетные маски, назначаемость адреса с `.0`, переполнение IPv4, форматы ответов.
- Для каждого из 12 типов и каждого префикса /1–/30 проверены 20 генераций:
  правильный ответ присутствует, варианты уникальны, имеют допустимый формат,
  данные без потерь проходят JSON-сериализацию.

Дополнительно изолированно проверены методы оценивания и восстановления состояния
для 12 типов в обоих режимах и загрузка старой попытки: суммарно **64 303
утверждения** с вычислительными проверками. Для этого запуска классы окружения
Moodle заменены минимальными заглушками; он не проверяет работу ядра или БД.

Дополнительно ответы 7 200 сгенерированных заданий (все типы и префиксы)
сверены с независимым расчётом через Python `ipaddress`: расхождений нет.

Расширены тесты Moodle для обоих режимов всех типов, восстановления старого
состояния, массового создания, экспорта/импорта XML и backup/restore нового поля.
Их полный запуск, миграция на настоящей БД и браузерная проверка версии 0.3.0
в этой среде пока не выполнены. Результаты 0.2.0 ниже относятся к прежней версии.

# Проверки версии 0.2.0

## Массовое добавление вопросов

На той же установке Moodle 5.3+, PHP 8.4.24 и PostgreSQL 17.11 выполнены:

- Обновление с версии плагина 0.1.0 до 0.2.0 через CLI Moodle, регистрация
  обработчика навигации и появление пункта в меню курса.
- **16 тестов PHPUnit, 8970 утверждений — все прошли.** Новые проверки:
  - создание 15 шаблонов в собственном банке теста и 15 штатных слотов;
  - сохранение префиксов и режима во всех шаблонах, отсутствие конкретных IP
    до начала попыток, правильная сумма баллов теста;
  - запуск настоящих попыток теста для двух учащихся: каждому доступны 15
    сгенерированных заданий, наборы различаются, состояние восстанавливается из БД;
  - запрет массового добавления после начала реальных попыток;
  - добавление в конец теста без изменения существующих слотов;
  - запрет операции учащемуся, проверка принадлежности теста выбранному курсу;
  - запрет пустых/неподдерживаемых префиксов, неизвестного режима и количества
    вне 1–100 без создания вопросов;
  - валидация полей формы.

- Браузерный сценарий Chromium/Playwright от преподавателя: пункт меню курса,
  количество по умолчанию 15, выбор теста и префикса /24, отправка одной формы,
  переход в штатный редактор с сообщением о добавлении 15 вопросов.
- Продолжение от учащегося: пункт генератора скрыт, в тесте отображаются 15
  сгенерированных заданий, все ответы сохраняются при возврате и обновлении,
  после сдачи Moodle показывает **15.00/15.00**. Условия и порядок вариантов
  совпадают при просмотре результата; ошибок JavaScript нет.

Ограничения среды, перечисленные ниже для версии 0.1.0, сохраняются.

## Проверки исходной версии 0.1.0

## Реально выполнено на Moodle 5.3

Официальная ветка `MOODLE_503_STABLE`, коммит
`236a9d702e62dc11f5aa66e4c8b5239cfc26c3d8`,
**Moodle 5.3+ (Build: 20261030)**. PHP **8.4.24**, PostgreSQL **17.11**,
PHPUnit **11.5.56**, Linux, стандартная тема Boost.

- Чистая установка Moodle вместе с `qtype_ipv4`, создание таблицы параметров,
  обнаружение типа вопроса штатной системой плагинов.
- Проверка синтаксиса всех PHP-файлов.
- **10 тестов PHPUnit, 8776 утверждений; ошибок и предупреждений нет.**
  - Расчёт сетей `/8`, `/16`, `/24`, включая крайние значения IPv4.
  - Валидация формата и удаление пробелов по краям.
  - Выбор только разрешённых префиксов и запрет пустого/неподдерживаемого набора.
  - 900 наборов вариантов: четыре уникальных адреса, ровно один правильный,
    два ошибочных адреса внутри исходной сети и одна другая сеть с нулевой
    частью узла; разные комбинации и порядок.
  - Оценивание правильного ответа и каждого дистрактора в обоих режимах.
  - Восстановление состояния из первого шага, включая сохранённый режим.
  - Сохранение настоящей попытки в PostgreSQL, загрузка, ответ, повторная загрузка,
    завершение, просмотр сохранённого состояния и переоценка через question engine.
  - Форма редактирования: сохранение выбранного префикса и режима, запрет
    снятия всех префиксов; повторная загрузка параметров из банка вопросов.
  - Экспорт и импорт Moodle XML с сохранением настроек.
  - Резервное копирование курса и восстановление банка вопросов в другой курс:
    параметры `/8,/24` и режим выбора сохранены.
- Настоящий тест Moodle с двумя вопросами, выполненный в Chromium через Playwright
  от имени учащегося:
  - ручной ввод и радиокнопки отображаются;
  - правильный ручной ответ с пробелами и правильный выбранный вариант принимаются;
  - переход на страницу завершения сохраняет ответы;
  - возврат к попытке и обновление страницы сохраняют IP, префикс, порядок
    вариантов и ответы;
  - после окончательной сдачи Moodle показывает **2.00/2.00, 100%**;
  - страница просмотра содержит прежние условия, варианты и ответы, оба вопроса
    оценены как правильные;
  - ошибок JavaScript в выполненном сценарии не обнаружено.

Команда итогового запуска (из корня подготовленного Moodle):

```sh
php vendor/bin/phpunit --testsuite qtype_ipv4_testsuite
```

Тестовая среда и журналы находятся в игнорируемой Git папке `work/`;
они не являются частью устанавливаемого плагина. Установку выполняли с отдельными
каталогами данных и префиксами таблиц для обычной и PHPUnit БД.

## Проверки, которые не удалось запустить в этой среде

- Полный браузерный сценарий с русским интерфейсом Moodle: базовый языковой пакет
  `ru` отсутствует, загрузка с `download.moodle.org` отклоняется сетевой политикой
  (HTTP 403). Русские строки плагина включены, их PHP-синтаксис проверен.
- Интеграционный прогон на PHP 8.3: небольшой контейнер PHP 8.3 доступен, но
  установка требуемых Moodle расширений из Alpine-репозитория блокируется
  сетевой политикой; большой готовый образ превышает доступное место.
  Полный интеграционный прогон выполнен на поддерживаемом Moodle 5.3 PHP 8.4.

## Дополнительное покрытие вне выполненного прогона

Не выполнялись полный набор тестов ядра Moodle/Behat, Moodle Mobile, другие темы,
браузеры, СУБД, нагрузочные испытания и все сочетания поведения вопросов.
Проверенный браузерный сценарий использует отложенный отзыв; полагаться на этот
прогон как на проверку всех поведений Moodle нельзя.
