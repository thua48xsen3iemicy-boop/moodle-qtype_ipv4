# Практикум — mod_practicum 0.1.0 (alpha)

Отдельный элемент курса Moodle 5.3. Преподаватель выбирает «Добавить элемент или
ресурс → Практикум», задаёт блоки и сохраняет. Обычный тест создавать не нужно.

## Установка

1. Сохраните установленный `qtype_ipv4` (не ниже 0.1.0).
2. Скопируйте этот каталог в `/var/www/moodle/public/mod/practicum`.
3. Из `/var/www/moodle` выполните от пользователя PHP:

```sh
sudo -u www-data php admin/cli/upgrade.php --non-interactive
sudo -u www-data php admin/cli/purge_caches.php
```

Для сборки двух отдельных ZIP из репозитория: `python3 tools/package.py`.
`dist/qtype_ipv4.zip` устанавливается в `public/question/type`,
`dist/mod_practicum.zip` — в `public/mod`. Не устанавливайте весь репозиторий
как один модуль. Архив модуля имеет верхний каталог `practicum/`.

## Настройка

- Название, описание, режим.
- Тренировка: без срока и ограничения числа попыток; проверка ответа непосредственно
  в вопросе, объяснение после проверки. После проверки вопрос фиксируется; для
  повторной тренировки запускается новая попытка. В журнал оценок результат не идёт.
- Контрольная: необязательный лимит времени и число попыток (0 — без ограничения).
  Обратная связь после сдачи. В журнал идёт лучший результат контрольных, шкала 0–100.
- Блоки: вид задания, число и параметры. «Добавить блок» добавляет ещё блок;
  количество 0 исключает блок. Суммарно 1–100 заданий.
- Реализован вид «IPv4: определение адреса сети». Префиксы выбираются независимо
  случайно из разрешённых. Все ответы — ручной ввод. Балансировка не применяется.

Набор генерируется при начале попытки. План, режим, срок, IP и ответы сохраняются.
Обновление страницы не генерирует новое условие. Изменение настроек влияет на новые
попытки. Шаблоны вопросов переиспользуются по настройкам; состояния попыток раздельны.

Нажимайте «Сохранить ответы» перед уходом со страницы. Автосохранения в этой
первой версии нет. По истечении срока принимаются только ранее сохранённые ответы;
страница автоматически перезагружается для отображения результата. Незавершённые
просроченные попытки также обрабатывает штатный cron Moodle (задача каждую минуту).
Работающий cron обязателен для завершения попыток закрывших браузер студентов.

Преподаватель видит список всех попыток, студент — своих. Завершённую попытку
можно просмотреть. Поддерживаются резервное копирование с попытками и Privacy API.

## Расширение и границы версии

`classes/local/task_type.php` — контракт семейства заданий, `registry.php` — реестр,
`blueprint.php` — планировщик. Сейчас разные блоки могут иметь разные настройки IPv4.
Linux-команды, пути и реальные VM ещё не реализованы. Контракт будущего изолированного
бэкенда и правила безопасности описаны в `docs/ARCHITECTURE.md` репозитория.

Alpha-версия: нет миграции обычных тестов в практикумы, автосохранения,
адаптивных повторов внутри одного вопроса, специальных исключений по времени,
расширенной аналитики и Moodle Mobile. Существующие тесты с qtype_ipv4 продолжают
работать отдельно. Полный набор возможностей mod_quiz здесь не воспроизводится.
